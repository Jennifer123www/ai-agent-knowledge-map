# 基于证据的推理配图稿

- 1536×1024 中文 PNG；图中“推理”只呈现可核对的证据与中间产物，不生成虚构的内部思维链。
- `reasoning-cover.png`：团队空闲、会议室、用户约束三项证据走向一个候选时间。

- `reasoning-conflict.png`：日历显示空闲但会议室被占时，候选不能直接成立。
- `reasoning-claim.png`：结论、证据、前提、待确认四格，避免无出处的肯定句。
- `reasoning-test.png`：证据新增、证据冲突、证据缺失、证据更正四种测试。
- `reasoning-principle.png`：借 ReAct Figure 1(1d) 画“查询日历 → 观察空闲 → 查询会议室 → 观察占用 → 调整结论”，不展示完整私有推理文本。

- [ReAct](https://arxiv.org/abs/2210.03629) Figure 1(1d)、§2–3，保留外部行动和观察让下一次判断有新证据的方向。
