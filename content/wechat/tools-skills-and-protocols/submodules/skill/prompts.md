# 技能子模块配图提示词

本组文章共用 6 张配图，均应使用 `gpt-image-2` 生成 1536x1024 PNG，暖白底、深墨绿与橙色为主，中文标签少而大，不出现水印和多余文字。

1. `skill-cover.png`：微信公众号文章封面。表现一本标准作业手册、步骤清单、工具箱和带勾的交付结果，标题文字为“AI Agent 的技能”，副标题为“把一次会做，变成每次都按章办”。
2. `skill-method-tool.png`：三栏关系图。左侧“技能”是一份带步骤和验收项的手册，中间“工具”是一个执行按钮，右侧“结果”是带证据的交付单；只保留这三个中文标签。
3. `skill-execution.png`：技能执行链。依次展示“输入”“发现”“执行”“验收”，每个节点配一个清晰图标，箭头从左向右，标签逐字准确。
4. `skill-discovery.png`：技能目录匹配图。用户任务卡片经过候选筛选，进入一份被选中的技能手册；画面标签为“任务”“技能目录”“候选筛选”“选中”。
5. `skill-recovery.png`：技能中断恢复图。展示“检查点”“状态查询”“继续执行”“人工接管”四个节点，突出先查状态再恢复，不要出现小字。
6. `skill-versioning.png`：技能版本发布图。展示版本 1、评测、灰度、版本 2 和回滚箭头，标签为“版本”“回归”“灰度”“回滚”。
