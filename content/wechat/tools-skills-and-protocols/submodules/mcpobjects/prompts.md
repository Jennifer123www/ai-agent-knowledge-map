# MCP 对象子模块配图提示词

共 6 张图，使用 `gpt-image-2`、1536x1024 PNG、暖白背景、中文大标签和清楚对象关系。

1. `mcpobjects-cover.png`：封面，Host 管理多个 Client，每个 Client 连接一个 Server，右侧展示工具、资料和模板，标题“MCP 里谁负责连接，谁提供工具和资料”。
2. `mcpobjects-roles.png`：Host、多个 Client、多个 Server 的层级图，标签“Host”“Client”“Server”。
3. `mcpobjects-primitives.png`：三栏对象，标签“Tools 工具”“Resources 资源”“Prompts 提示模板”。
4. `mcpobjects-security.png`：三类对象分别经过动作授权、数据授权、模板治理，标签“动作”“数据”“模板”“本地策略”。
5. `mcpobjects-routing.png`：任务先读 Resource，再用 Prompt 整理，最后调用 Tool，标签“读取资料”“使用模板”“执行动作”。
6. `mcpobjects-elicitation.png`：Server 请求补充信息，Host 展示界面，用户确认后返回，标签“Server 发问”“Host 展示”“用户决定”。
